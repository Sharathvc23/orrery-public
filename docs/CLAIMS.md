# Claims vs reality — the honesty matrix

Every capability Orrery advertises, adjudicated against evidence. The standing
rule is **don't claim what isn't proven**: if a claim in the README,
[`PRODUCT.md`](./PRODUCT.md), [`API.md`](./API.md), or a subsystem README can't
be tied to a test, an endpoint, or live-mesh observation, it gets hedged or
removed. This page is the audit trail for that rule.

**Verdicts** — ✅ **PROVEN**: cited evidence exercises the claim end-to-end
(a CI-gated test, a code path verified against the live mesh, or both) ·
◐ **PARTIAL**: the mechanism exists and is partially exercised; the un-exercised
part is stated · ✗ **ASPIRATIONAL**: not true today — must appear only in
[`ROADMAP.md`](./ROADMAP.md), never as a capability · ⚠️ **DOWNGRADED**: was
claimed, was found untrue in some real case, and stays here rather than being
deleted so the reason is legible · ✂️ **NOT BUILT / OUT OF SCOPE**: the claim was
withdrawn from the docs entirely; the row survives so a reader who remembers the
old claim finds out what happened to it · ✅\* **PROVEN, narrower than it read**:
true on the surface named, and the row says which · ⚑ **TRUE ON `main`, NOT YET
DEPLOYED**: the code is merged and gated, and the mesh a reader can `curl` today
still behaves the old way — the row says what each one does.

## Two reference points, because one verdict cannot answer both questions

A reader of this page is asking one of two different questions — *what does this
software do?* and *what does the thing I am talking to right now do?* — and until
today the page answered only the first while reading as though it answered both.

**Every verdict here is adjudicated against `main` unless the row carries ⚑.**
A count or a verdict on this page is pinned to the SHA above and is not a claim
about whatever `main` happens to be when you read it — re-derive against the pin
before concluding a number is stale.
A ⚑ row is one where those two answers differ, and it names both.

- **`main` @ `2da8509`** — what the code does. Reproducible: check it out and run
  the suites cited.
- **Deployed mesh @ `3f94cc5`** (the commit that made a published listing state
  what was checked about its owner, merged 2026-08-22) — what the three live
  orgs actually serve. Read from the running servers, not inferred:
  `/health` on all three of `server-production-9ec7`, `-c3f5` and `-c4d4`
  reports `git_commit: 3f94cc5…`. It is an ancestor of `main`, so it can be
  checked out and reproduced too.
- **The gap is 49 commits** (`git rev-list --count 3f94cc5..main`), spanning
  today's privacy, auth and served-claims work. Every ⚑ row below sits in it.

The distinction is not pedantry: on 2026-08-27 the deployed anonymous thoughts
feed was probed at `limit=30` and **29 of the 30 rows carried a member handle**,
in the prose *and* in the A2UI card title, with the `targets` field present on
all 30. The redaction that makes those rows safe is on `main` and is not running.
A reader who took this page as describing production would have been wrong about
the single most sensitive thing on it.
